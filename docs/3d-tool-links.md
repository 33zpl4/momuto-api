_Generated by `node scripts/audit-3d-links.js` (12 Oct 2026). Do not edit by hand: change the links, run the script, commit both. CI fails a PR whose links and this inventory disagree, so a new page with a launch link is always recorded here._

## What a launch link does
- `configId` is **not** a pinned design. The tool opens what the visitor's session holds for that id and, for a never-seen id, the collection default: `mamuto3` `designQDefault` in `3d-configurator/asset/defines-ext.js` (THE CASCADE since 12 Oct 2026).
- So changing the opening design is a **one-line change in defines-ext.js** (bump `?v=` in chunks 908/161) — no page needs editing.
- To open a SPECIFIC design from a link instead: `--set u=<shareId> --set useGetShare=true` (copy-on-open). Save the design in the tool, press Share, take `u` from the link.
- `userId=userIdUrl` is a placeholder the tool replaces with a real session id.
